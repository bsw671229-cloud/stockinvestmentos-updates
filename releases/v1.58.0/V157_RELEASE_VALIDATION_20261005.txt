Release theme
-------------
Safe Update Orchestrator / One-Click Publish & Install.

Purpose
-------
Reduce the repeated manual Updater2 workflow while preserving explicit
human authorization for remote publication and software installation.

New functionality
-----------------
1. Release Manager 0A Safe Update Orchestrator
2. Automatic inbox preflight after an out-of-band SHA-256 is entered
3. One confirmed action:
   Approve -> Local Publish -> Deployment Preview -> Git Push -> Public Verify
4. Separate confirmed install action for a publicly verified Approved RELEASE
5. Post-restart E2E Health + non-mutating Recovery Drill finalize action
6. Idempotent retry when static hosting propagation delays Public Verify
7. Public version and package SHA-256 must match the Approved RELEASE before install
8. CLI fallback commands for preflight/release/install/finalize
9. 0B/0C/0D/0E remain available as detailed Advanced controls
